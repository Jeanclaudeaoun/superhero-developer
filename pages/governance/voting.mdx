# Voting on Polls

> **Page brief** — Short and procedural. Emphasise reading the poll before voting so option numbers are right.
>
> `status: outline` · `depth: standard`

Always read the poll first to confirm the option numbering and that it is still open:

```bash
node scripts/superhero-governance.mjs info <poll_address>
node scripts/superhero-governance.mjs vote <poll_address> <option_number>
node scripts/superhero-governance.mjs revoke <poll_address>
```
