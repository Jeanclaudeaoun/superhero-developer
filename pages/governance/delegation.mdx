# Delegation

> **Page brief** — Document the delegation model in the Registry contract and what it means for stake weighting.
>
> `status: outline` · `depth: standard`

```bash
node scripts/superhero-governance.mjs delegate <ak_address>
```

| `Registry` entrypoint | Purpose |
| --- | --- |
| `delegate(delegatee)` | Delegate your stake |
| `revoke_delegation()` | Take it back |
| `delegatee(account)` | Who an account delegates to |
| `delegators(account)` | Who delegates to an account |
| `delegations()` | The full delegation map |
