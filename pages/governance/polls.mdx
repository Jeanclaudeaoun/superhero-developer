# Polls

> **Page brief** — Explain the poll data model and — critically — which result figure is authoritative.
>
> `status: outline` · `depth: deep`

```bash
node scripts/superhero-governance.mjs list
node scripts/superhero-governance.mjs info <poll_address>
node scripts/superhero-governance.mjs info-by-id <poll_id>
```

**Read `stake_weighted_results` as the official outcome.** `raw_vote_counts` counts addresses
only and is not the result.

| `Poll` entrypoint | Purpose |
| --- | --- |
| `title()`, `metadata()`, `close_height()` | Poll identity and deadline |
| `votes()` | All cast votes |
| `vote(option)` / `revoke_vote()` | Cast or retract |
| `has_voted(voter)`, `voted_option(voter)` | Per-voter state |
| `is_closed()`, `is_author(author)` | Status checks |
