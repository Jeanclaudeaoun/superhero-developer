# Contributing to These Docs

Read this before you edit anything. It is short; the two pages it links to are the substance.

## What this site is

Documentation for Superhero, written from two source repositories — the web app and the AI agent
skill — rather than from memory. That constraint is the whole point. Every number, address,
endpoint and entrypoint on this site should trace back to a file someone actually read.

## The three rules that matter

1. **Never invent a fact.** If you cannot verify something, put it under `## Open questions` on
   that page. A page with three honest open questions is worth more than a page with three
   plausible fabrications, because a reader cannot tell a fabrication from the verified material
   around it.
2. **Every page ends with `## Read more`.** Two to five internal cross-links with a reason each,
   plus one to four external links where they genuinely help. This is what turns a pile of pages
   into a site.
3. **Run the linter before you finish.** `python3 scripts/lint-mdx.py` must print `0 issues`. It
   catches the MDX mistakes that break `next build`, broken internal links, and `_meta.json`
   drift.
