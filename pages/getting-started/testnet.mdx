# Using Testnet

> **Page brief** — Everything needed to run against `ae_uat`: endpoints, contract addresses, a faucet, and how to point each client at testnet.
>
> `status: outline` · `depth: deep`

Superhero builds are network-pinned at build time via `VITE_NETWORK` (`ae_mainnet` or `ae_uat`).

| Setting | Mainnet (`ae_mainnet`) | Testnet (`ae_uat`) |
| --- | --- | --- |
| Backend / API | `https://api.superhero.com` | `https://testnet.api.dev.tokensale.org` |
| Node | `https://mdw.wordcraft.fun` | `https://testnet.aeternity.io` |
| Middleware | `https://mdw.wordcraft.fun/mdw` | `https://testnet.aeternity.io/mdw` |
| Explorer | `https://aescan.io` | `https://testnet.aescan.io` |
| Compiler | `https://v7.compiler.aepps.com` | `https://v7.compiler.aepps.com` |
| Governance API | `https://governance-server-mainnet.prd.service.aepps.com/` | `https://governance-server-testnet.prd.service.aepps.com/` |
