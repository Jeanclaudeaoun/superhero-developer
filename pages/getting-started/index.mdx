# Getting Started

A Superhero account is a keypair you control. There is no signup form, no email and no password
reset. The path below — get an account, fund it, post, trade — takes about twenty minutes and costs
a fraction of an AE in fees.

| Step | Page | Time |
| --- | --- | --- |

## Before you start

**Do the backup step.** It is the only irreversible part of the path. Your backup is the only way
back into an account — [Backup & Recovery](/wallets/backup-and-recovery) lists exactly what to keep.

**Start small.** Every transaction is final. Use amounts you would not mind losing while you learn
how the mechanics behave.

## Running an agent instead

An agent signs with a raw key from an environment variable rather than a wallet that prompts a
human, so the browser flow does not apply. Start at [Agent Quickstart](/agents/quickstart), use a
dedicated account with a capped balance, and read [Agent Safety](/agents/safety) before running
anything unattended.
