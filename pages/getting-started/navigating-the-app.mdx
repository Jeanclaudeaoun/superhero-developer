# Navigating the App

superhero.com is a single-page app with a flat route table. Browsing is always open: every page
renders without a wallet, and a page whose primary action needs an account shows a Connect control
in place of that action. The **Wallet** column below says which actions those are.

## Social

| Path | What it is | Wallet |
| --- | --- | --- |
| `/` | The social feed | To post, comment or tip |
| `/post/:slug` | A single post and its comment thread | To comment or tip |
| `/users/:address` | A user profile | To edit your own |
| `/profile/x/callback` | OAuth landing page for the Connect X flow | Part of a signed flow |

`:slug` also accepts a post id, which redirects to the canonical slug.

## Trends and tokens

| Path | What it is | Wallet |
| --- | --- | --- |
| `/trends/tokens` | Trending community tokens | No |
| `/trends/tokens/:tokenName` | A token page: feed and chat, trade card, info, transactions, holders | To trade |
| `/trends/create` | Create a new community token | **Yes** |
| `/trends/daos` | All community DAOs | No |
| `/trends/dao/:saleAddress` | One community's DAO | To propose or vote |
| `/trends/dao/:saleAddress/vote/:voteId/:voteAddress` | A single DAO vote | To vote |
| `/trends/accounts` | Trader and creator accounts | No |
| `/trends/accounts/:address` | One account's tokens, creations and activity | No |
| `/trends/leaderboard` | Leaderboards | No |
| `/trends/invite` | Invite links and the affiliate program | **Yes** |
| `/trends/visx` | The trend cloud visualisation | No |
| `/trends` | Redirects to `/trends/tokens` | — |

The **list** is `/trends/daos`; a **single DAO** is `/trends/dao/:saleAddress`. The parameter is a
**sale address**, not the AEX-9 token address.

## Chat

| Path | What it is | Wallet |
| --- | --- | --- |
| `/chat` | Chat inbox — all, communities and DMs | **Yes** |
| `/chat/:saleAddress` | A token-gated community room | **Yes** |
| `/chat/:saleAddress/info` | Room info and members | **Yes** |
| `/chat/dm/:address` | A direct-message thread | **Yes** |
| `/chat/settings/relays` | Relay configuration | **Yes** |

Chat identity is derived from your wallet, so chat needs one throughout.

## Governance

| Path | What it is | Wallet |
| --- | --- | --- |
| `/voting` | Polls, delegation and your voting activity | To vote or delegate |
| `/voting/p/:id` | A single poll | To vote |
| `/voting/account` | Your governance account view | To act |
| `/voting/create` | Create a poll | **Yes** |

All four render the same Governance view; the path selects the tab.

## Wallet, utility and reference

| Path | What it is | Wallet |
| --- | --- | --- |
| `/wallet` | The Superhero Wallet product page — features, downloads and a wallet FAQ | No |
| `/tx-queue/:id` | Callback landing page for deep-link signing results | Part of a signing flow |
| `/get-ae` | Ways to get AE: earn, exchanges and swap providers | No |
| `/meet/:room?` | Video conference room | No |
| `/landing` | The marketing landing page | No |
| `/whitepaper` | The full technical whitepaper | No |
| `/faq` | Frequently asked questions | No |
| `/branding` | Brand assets | No |
| `/terms` · `/privacy` | Legal pages | No |

`/wallet` is a product page about Superhero Wallet, not the built-in wallet's interface. The
built-in wallet is reached through **Connect** wherever you are.

## Redirects

Old links keep working:

| From | To |
| --- | --- |
| `/trending`, `/trending/tokens` | `/trends/tokens` |
| `/trending/visx`, `/trending/invite`, `/trending/daos`, `/trending/accounts`, `/trending/create`, `/trending/leaderboard` | the matching `/trends/*` path |
| `/trending/tokens/:tokenName` | `/trends/tokens/:tokenName` |
| `/trending/dao/:saleAddress` and its vote path | the matching `/trends/dao/*` path |
| `/trending/accounts/:address` | `/trends/accounts/:address` |
| `/user/:address` | `/users/:address` |
| `/post/:slug/comment/:id` | `/post/:id` — a comment is itself a post |
| `/buy-ae` | `/get-ae` |
| `/swap` | `/defi/swap` |

Legacy DEX paths that still render their own view rather than redirecting: `/pool`, `/explore`,
`/explore/tokens/:id`, `/explore/pools/:id` and `/pool/add-tokens`.

Anything else renders the not-found page.
