# Replaceable DAOs

> **Page brief** — Document the upgrade path — this is the protocol's main forward-compatibility story.
>
> `status: outline` · `depth: standard`

`ReplaceableDAO.aes` defines the interface a community-provided DAO must implement to be used
with the system and to be swapped in via a `ChangeDAO` vote.

| Entrypoint | Purpose |
| --- | --- |
| `is_dao()` | Must return `true`; the safeguard that blocks transfers to non-DAO addresses |
| `get_community_management()` | The linked community management contract |
| `record_sale_transaction(address, int)` | Receive sale proceeds with metadata, instead of a bare `Chain.spend` |

`record_sale_transaction` exists so a replacement DAO can add its own logic for how proceeds
are split or used — an explicit upgrade path.
