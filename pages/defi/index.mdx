# DeFi & DEX

Superhero embeds a full automated market maker at `/defi`. You can swap any pair that has a
pool, provide liquidity and earn fees, wrap AE into its AEX-9 form, and browse every token,
pool and transaction on the exchange.

**This is a different market from the bonding curve.** Readers mix the two up constantly, so
start with the distinction before anything else.

## The DEX is not the bonding curve

| | Bonding curve (community tokens) | DEX (AMM) |
| --- | --- | --- |
| Where | `/trends/tokens/...` | `/defi/swap` |
| What sets the price | A fixed exponential formula on supply | The ratio of two pool reserves |
| What happens when you buy | Tokens are **minted** against the curve | Tokens are **bought from a pool**, nothing is minted |
| What happens when you sell | Tokens are **burned** back to the curve | Tokens go **into the pool** |
| Counterparty | The curve contract's reserve | Other liquidity providers |
| Contracts | `AffiliationBondingCurveTokenSale`, `BondingCurveExponential` | `AedexV2Router`, `AedexV2Factory`, `AedexV2Pair` |
| Fee | 1% spread, split 0.5% DAO and 0.5% affiliation | 0.3% per swap, to liquidity providers |
| Can it run out of liquidity | No — the reserve always covers the full supply | Yes — a thin pool gives terrible prices or no route at all |
| Main risk | Price falls back down the curve | Price impact, no route, and impermanent loss if you provide liquidity |

Two consequences worth internalising:

- **A community token's curve price and any DEX price for the same token are independent.**
  Nothing arbitrages them automatically.
- **Bonding-curve solvency guarantees do not transfer.** The curve can always buy back its
  entire supply; a liquidity pool offers no such promise. If the liquidity providers leave,
  you cannot sell at any price.

## Routes

| Route | What it does |
| --- | --- |
| `/defi` | Redirects to `/defi/swap` |
| `/defi/swap` | The swap form, a candlestick chart for the selected pair, and recent activity |
| `/defi/pool` | Your liquidity positions, plus the add and remove forms |
| `/defi/pool/add-tokens` | Add-liquidity flow for a pair you pick |
| `/defi/wrap` | Wrap AE into WAE and unwrap it back |
| `/defi/explore/tokens` | Every token the DEX indexes |
| `/defi/explore/tokens/<address>` | One token's detail page |
| `/defi/explore/pools` | Every pair |
| `/defi/explore/pools/<address>` | One pool's detail page |
| `/defi/explore/transactions` | Filterable feed of every DEX transaction |
| `/defi/bridge` | **Disabled.** Redirects to `/defi/swap` — see [Bridging from Ethereum](/defi/bridge) |
| `/defi/buy-ae-with-eth` | **Disabled.** Redirects to `/defi/swap` |

`/swap`, `/pool`, `/explore` and `/pool/add-tokens` still resolve as legacy paths.
