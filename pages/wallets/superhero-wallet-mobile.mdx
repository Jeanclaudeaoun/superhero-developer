# Superhero Wallet — Mobile

> **Page brief** — Cover the native apps, the built-in wallet, and the PWA install path for people who do not want an app store.
>
> `status: outline` · `depth: deep`

| Platform | Link |
| --- | --- |
| iOS | `https://apps.apple.com/us/app/superhero-web3-communities/id6758045846` |
| Android | `https://play.google.com/store/apps/details?id=com.superhero.apps` |

The app ships with a wallet built in, so you can post, trade, tip and govern without an
extension. Superhero is also installable as a PWA — "Add to Home Screen" in Safari, or the
install prompt on Android — which gives a full-screen experience, an integrated wallet and
push notifications without an app store.
