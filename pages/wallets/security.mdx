# Wallet Security

> **Page brief** — Practical, opinionated security guidance. Reuse the DO/DON'T table from the agent skill and extend it to human users.
>
> `status: outline` · `depth: deep`

The agent skill ships this table; it applies just as well to people.

| ✅ Do | ❌ Don't |
| --- | --- |
| Keep private keys in environment variables | Store private keys in plain-text files |
| Use `export AE_PRIVATE_KEY=<key>` in your shell | Commit wallet files to git |
| Back up mnemonics offline | Log or print a private key |
| Share invite links directly with the recipient | Log or commit invite links (they contain one-time secrets) |
| Verify the address and amount before signing | Sign a transaction you do not understand |
