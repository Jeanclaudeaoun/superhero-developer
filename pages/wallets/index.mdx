# Wallets

Superhero never holds your keys. Everything you do that touches the chain — posting, tipping,
trading, voting — is a transaction signed by a wallet you control.

Two different things are called "a wallet" on Superhero:

1. **Superhero Wallet** — the standalone multi-chain wallet, built three ways: a browser extension,
   native iOS and Android apps, and the hosted web build at `wallet.superhero.com`.
2. **The built-in wallet** — a wallet created and held inside the Superhero app itself, unlocked
   with a passkey or passphrase.

Both hold the same kind of æternity account (`ak_...`) on the same derivation path, so the same
seed phrase gives you the same addresses in either. Pick based on how you use the app and on which
recovery model you can live with.
