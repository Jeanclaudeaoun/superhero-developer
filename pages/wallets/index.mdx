# Wallets

Superhero never holds your keys. Everything you do that touches the chain — posting, tipping,
trading, voting — is a transaction signed by a wallet you control. This section covers every wallet
that works with Superhero, how to connect one, and how to get back in when something goes wrong.

Superhero works with two different things people call "a wallet":

1. **Superhero Wallet** — the standalone multi-chain wallet. One codebase
   (`superhero-com/superhero-wallet`) built three ways: a browser extension, native iOS and Android
   apps, and the hosted web build served at `wallet.superhero.com`.
2. **The built-in wallet** — a wallet created and held inside the Superhero app itself, unlocked
   with a passkey or passphrase. This is what the mobile app means by "wallet built in, no
   extensions, no friction".

Both hold the same kind of æternity account (`ak_...`), derived on the same path — so the same seed
phrase gives you the same addresses in either. Pick based on how you use the app, and on which
recovery model you can actually live with.
