# Social

Posts and comments are written to the `Tipping` v3 contract, so they are permanent,
attributable and impossible to delete. Chat is deliberately *not* on-chain: it runs over Nostr
relays for realtime messaging. Know which is which before you publish anything.

## On-chain or not

| Surface | Where it lives | Permanent? |
| --- | --- | --- |
| Posts | `Tipping` v3 contract, one entry per `tip_id` | Yes — no edit, no delete |
| Comments | The same contract, with a `comment:` media prefix | Yes |
| Tips | A plain AE transfer with a payload naming the post | Yes — it is a transaction |
| Hashtags and topics | Derived by the indexer from post content | Follow the posts |
| Chat messages | Nostr relays, off-chain | No — relay-dependent |
| Notifications | The Superhero API, delivered over a socket and web push | No |
| Moderation state | `CommunityManagement.aes` per community | Yes, but it hides rather than deletes |
