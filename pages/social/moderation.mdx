# Moderation

> **Page brief** — Explain community-level moderation: moderators appointed by DAO vote, muting, and write thresholds.
>
> `status: outline` · `depth: deep`

Content cannot be removed from the chain, so moderation happens at the community application
layer through token-holder governance rather than at the protocol level.

`CommunityManagement.aes` holds the moderation state for each community:

| Entrypoint | Purpose |
| --- | --- |
| `moderator_accounts()` | The current moderator set |
| `muted_user_ids()` | Muted user identifiers |
| `minimum_token_threshold()` | Tokens required for write access |
| `add_moderator(moderator)` / `delete_moderator(moderator)` | Appointed and removed by DAO vote |
| `mute_user_id(user_id)` / `unmute_user_id(user_id)` | Moderator actions |
| `change_minimum_token_threshold(n)` | Changed by DAO vote |
