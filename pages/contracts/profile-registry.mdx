# ProfileRegistry

> **Page brief** — Full reference for ProfileRegistry.aes. The ACI is not yet vendored, so this page starts from the whitepaper.
>
> `status: outline` · `depth: standard`

Known entrypoints from the whitepaper:

| Entrypoint | Purpose |
| --- | --- |
| `set_custom_name` | Claim an unverified custom name |
| `set_chain_name` | Link an AENS name with its expiration |
| `set_x_name_with_attestation` | Link an X handle via a signed backend attestation |
| `set_display_source` | Choose `Custom`, `Chain` or `X` as the rendered identity |
| `get_state` | Full state: profiles, name maps, used nonces, version (`"v1"`) |
