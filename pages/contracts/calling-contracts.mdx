# Calling Contracts

> **Page brief** — The practical integration page: initialise an SDK, attach an ACI, call an entrypoint, handle the result.
>
> `status: outline` · `depth: deep`

The agent skill uses `@aeternity/aepp-sdk` together with `bignumber.js`:

```bash
npm install @aeternity/aepp-sdk bignumber.js
```

Every script in the skill follows the same shape: build an account from `AE_PRIVATE_KEY`,
connect to a node, initialise a contract from its vendored ACI plus an address, then call an
entrypoint. The ACI files in `superhero-agent-skill/contracts/` are the ones to use.
