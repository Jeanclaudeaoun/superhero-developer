# Smart Contracts

> **Page brief** — The contract-level reference. Entrypoint tables here are transcribed from the vendored ACI files and should stay machine-checkable against them.
>
> `status: outline` · `depth: overview`

All Superhero contracts are written in **Sophia** and run on the **FATE** virtual machine. The
ACI (contract interface) JSON files used to generate these tables are vendored in the agent
skill repository under `contracts/`.

| Contract | Role |
| --- | --- |
| `Tipping.aes` (v3) | Post registry and delegated posting |
| `CommunityFactory.aes` | Collections, community deployment, ProtocolDAO minting |
| `AffiliationBondingCurveTokenSale.aes` | Buy/sell against the curve, affiliation fees |
| `BondingCurveExponential.aes` | Price computation |
| `DAO.aes` / `DAOVote.aes` / `ReplaceableDAO.aes` | Treasury and governance |
| `CommunityManagement.aes` | Moderators, thresholds, metadata |
| `AffiliationTreasury.aes` | Referral accounting and payouts |
| `FungibleTokenFull.aes` | The AEX-9 token implementation |
| `ProfileRegistry.aes` | Identity, profiles and names |
| `Registry.aes` / `Poll.aes` | æternity governance polls |

Sophia is a functional language with strong typing and no mutable global state, which
narrows the surface for reentrancy and state-corruption bugs. The suite is designed for
independent audit and formal verification.
