# BondingCurveExponential

> **Page brief** — Full reference for the curve contract. Pair it with the conceptual page at /tokens/bonding-curve.
>
> `status: outline` · `depth: reference`

Implements the `BondingCurve.aes` interface.

| Entrypoint | Signature | Notes |
| --- | --- | --- |
| `buy_price` | `(total_supply: int) => int` | Instantaneous buy price |
| `sell_price` | `(total_supply: int) => int` | Instantaneous sell price |
| `calculate_buy_price` | `(total_supply: int, count: int) => int` | Cost of buying `count` |
| `calculate_sell_return` | `(total_supply: int, sell_tokens: int) => int` | Return from selling |
| `buy_curve` | `(x: int) => Frac.frac` | Curve value as a rational |
| `sell_curve` | `(x: int) => Frac.frac` | Curve value as a rational |
| `get_k` | `() => int` | Exponent coefficient |
| `get_initial_price` | `() => int` | Curve constant |
| `get_minimum_count` | `() => int` | Minimum tradable count |
| `get_sell_return_percentage` / `get_sell_return_precision` | `() => int` | The 99.5% sell factor |
| `curve_type` / `supported_decimals` | — | Metadata |
