# Factory & Contracts API

> **Page brief** — Document the discovery endpoints, so integrators stop hardcoding addresses.
>
> `status: outline` · `depth: standard`

| Method & path | Notes |
| --- | --- |
| `GET /api/factory` | The active community factory schema — address, collections, rules |
| `GET /api/contracts` | Deployed contract addresses |
| `GET /api/stats` | Platform stats |

The agent skill uses `GET /api/factory` to discover the current collection (`WORDS-ak_...`)
rather than hardcoding it — integrators should do the same.
