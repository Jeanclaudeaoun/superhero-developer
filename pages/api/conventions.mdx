### Pagination

List endpoints return `items` plus a `meta` block:

| Field | Meaning |
| --- | --- |
| `currentPage` | The page just returned |
| `totalPages` | Total pages available |
| `totalItems` | Total matching records |
| `itemCount` | Records in this response |

Common query parameters: `page`, `limit`, `order_by`, `order_direction`, `search`.
