# Profile API

> **Page brief** — The only part of the API with write endpoints — document the auth model carefully.
>
> `status: outline` · `depth: reference`

| Method & path | Notes |
| --- | --- |
| `GET /api/profile/{address}` | A single profile |
| `GET /api/profile` | The authenticated profile |
| `GET /api/profile/feed` | The profile's feed |
| `PATCH /api/profile/{address}` | Update profile fields |
| `POST /api/profile/{address}/challenge` | Request a signing challenge |
| `POST /api/profile/x/attestation` | Obtain a signed X attestation for the contract |
