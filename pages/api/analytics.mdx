# Analytics API

> **Page brief** — Document the analytics endpoints — useful for dashboards and for anyone sizing the network.
>
> `status: outline` · `depth: reference`

| Method & path | Returns |
| --- | --- |
| `GET /api/analytics/total-market-cap` | Total market cap across all tokens |
| `GET /api/analytics/total-created-tokens` | Lifetime token count |
| `GET /api/analytics/total-unique-users` | Lifetime unique users |
| `GET /api/analytics/daily-created-tokens-count` | Token creations per day |
| `GET /api/analytics/daily-trade-volume` | Trade volume per day |
| `GET /api/analytics/daily-unique-active-users` | DAU series |
| `GET /api/analytics/daily-market-cap-sum` | Market cap series |
| `GET /api/analytics/past-24-hours` | Rolling 24-hour summary |
| `GET /api/analytics/preview` | Summary payload |
| `GET /api/coins/aeternity/rates` | AE fiat rates |
| `GET /api/coins/aeternity/market-data` | AE market data |
