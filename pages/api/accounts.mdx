# Accounts API

> **Page brief** — Document the account endpoints including the portfolio history that agents rely on.
>
> `status: outline` · `depth: reference`

| Method & path | Notes |
| --- | --- |
| `GET /api/accounts` | Account list |
| `GET /api/accounts/{address}` | `bio`, `chain_name` and the rest of the account DTO |
| `GET /api/accounts/{address}/tokens` | Tokens held by an account |
| `GET /api/accounts/{address}/portfolio/history` | Portfolio value snapshots and PnL |
| `GET /api/accounts/leaderboard` | Top accounts |
