# DEX API

> **Page brief** — Document the DEX endpoints, which are served from both the Superhero API and a separate DEX backend.
>
> `status: outline` · `depth: standard`

Superhero API routes: `/api/dex/tokens`, `/api/dex/transactions`, `/api/dex/pairs/*`.

There is also a separate DEX backend:

| Network | URL |
| --- | --- |
| Mainnet | `https://dex-backend-mainnet.prd.service.aepps.com` |
| Testnet | `https://dex-backend-testnet.prd.service.aepps.com` |
