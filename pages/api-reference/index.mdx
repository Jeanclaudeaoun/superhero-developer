# API Reference

`api.superhero.com` is the read API behind Superhero: tokens and their prices, posts and topics,
accounts and portfolios, the DEX, trending and analytics. Reads need no credential. Writes are
authorised by a wallet signature over a server-issued challenge, not by an API key.

```bash
curl -s "https://api.superhero.com/api/tokens?order_by=trending_score&order_direction=DESC&limit=5"
```

Start with [Conventions](/api-reference/conventions) — pagination, units, errors, rate limits and
the write flow are shared by every endpoint and are not repeated per page.

## Base URLs

| Network | Base URL | Chain id |
| --- | --- | --- |
| Mainnet | `https://api.superhero.com` | `ae_mainnet` |
| Testnet | Not publicly documented | `ae_uat` |

Both hosts serve identical paths. Every path begins with `/api/`.
