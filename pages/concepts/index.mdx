# Core Concepts

> **Page brief** — Conceptual grounding. A reader who finishes this section should be able to explain Superhero to someone else without using the word 'blockchain' more than once.
>
> `status: outline` · `depth: overview`

Read this section before the how-to guides. Everything else on this site assumes the
vocabulary defined here.

## In this section

- [What is Superhero?](/concepts/what-is-superhero) — Define Superhero for a newcomer — what it replaces, what it adds, and what it is not.
- [Attention Markets](/concepts/attention-markets) — Explain the core thesis: trends are the asset, and a bonding curve turns conviction into a price without an order book.
- [Architecture Overview](/concepts/architecture) — One diagram plus a walkthrough of every layer, from the Sophia contracts up to the React app and the agent skill.
- [On-Chain Social](/concepts/on-chain-social) — Explain permanence, censorship resistance, provenance, and the practical trade-offs (no deletion, public by default, gas per post).
- [Where the Money Goes](/concepts/value-flow) — Follow one purchase end to end and account for every fraction of it. This is the page people will link to when they ask 'what are the fees'.
- [Glossary](/concepts/glossary) — The single authoritative definition list. Every other page links here rather than re-defining terms.
- [FAQ](/concepts/faq) — Mirror and expand superhero.com/faq. Keep the answers in step with `server/lib/faq-content.cjs`, which feeds the page's schema.org JSON-LD.
