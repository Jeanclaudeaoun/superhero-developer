# Resources

Reference material that does not belong in a numbered guide: the whitepaper and where each of its
sections is covered, the brand kit, how to file a bug report that can be acted on, and the list of
official URLs.

## In this section

| Page | Use it when |
| --- | --- |
| [Whitepaper](/resources/whitepaper) | You want the protocol specification, or need to find which page covers a given whitepaper section. |
| [Brand & Media](/resources/brand) | You are writing about Superhero, building an integration, or need the logo and palette. |
| [Support](/resources/support) | Something is broken and you want the report to be useful. |
| [Official Links](/resources/links) | You want to confirm that a URL you were sent is really Superhero. |

## The short answers

- **Whitepaper:** [superhero.com/whitepaper](https://superhero.com/whitepaper), version 0.7,
  February 2026.
- **Bug reports and feedback:** [github.com/superhero-com/superhero/issues](https://github.com/superhero-com/superhero/issues) —
  where the app's own "Send Feedback" button goes.
- **Official domains:** `superhero.com` and `wallet.superhero.com`. Check any other URL against
  [Official Links](/resources/links) before connecting a wallet.
