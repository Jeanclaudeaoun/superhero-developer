# Official Links

This is an anti-phishing reference first and a convenience page second. **Every URL below appears in
the Superhero repositories or in official æternity documentation.** Anything not on this page has
not been verified from those sources — which does not make it hostile, but does mean you should not
connect a wallet to it on this page's authority.

URLs are shown as literal strings rather than links in the tables, so you can compare them character
by character against whatever you were sent.

## The rule

> Superhero lives on `superhero.com` and `wallet.superhero.com`. Nothing else is the app.

Check the domain before you sign anything. A phishing site can copy the entire interface — the
palette, the logo, the copy — but it cannot copy the domain. The registered marks are also
protected: using Superhero branding on another domain is both a fraud signal and, per
[the terms](https://superhero.com/terms), a breach.

## What is not on this list

**No social media accounts.** No Discord server, Telegram group, X account, Reddit community, forum
or mailing list for Superhero could be verified from the web app, its locale files, or the agent
skill. The only X and Telegram references in the codebase are share intents — the buttons that post
*your* content to *your* accounts — and the OG banner's description of the card used when someone
shares a link. The FAQ's reference to "official channels listed in the app" could not be resolved to
a concrete channel in these sources.

Treat that as a live risk. An unofficial Discord or Telegram claiming to be Superhero support is the
standard setup for a key-phishing or fake-airdrop scam, and this page cannot tell you which invites
are legitimate. Until an official channel is published by Superhero itself, use the GitHub tracker
and the email address above, and assume anyone who direct-messages you offering help is not support.

**No other domains.** `superhero.io`, `superhero.app`, `superhero.finance`, `superheroswap.com` and
anything similar are not referenced anywhere in these repositories. A "Superhero" token sale,
airdrop, presale, migration or wallet-verification page on any domain other than the two above is
not Superhero.

**No one ever needs your key.** Not support, not a migration, not a verification, not an airdrop
claim, not a "wallet sync". Every legitimate Superhero action is a transaction you sign in your own
wallet. See [Security Best Practices](/wallets/security).

## Open questions

- **Does Superhero operate any official social or community channel?** Nothing in these repositories
  identifies one, yet the FAQ refers to "official channels listed in the app". The app's own footer
  links only to the GitHub repository and issue tracker. This should be settled from an official
  announcement before any invite link is added to this page.
- **Who operates `mdw.wordcraft.fun`?** It is the configured mainnet node and middleware origin in
  `src/config.ts` but is not an `aeternity.io` or `superhero.com` domain, and neither repository
  identifies its operator.
- **Is `testnet.api.dev.tokensale.org` a permanent testnet endpoint?** The hostname suggests a
  development deployment rather than a stable service, and nothing in these sources states its
  status.
