# Official Links

This is an anti-phishing reference first and a convenience page second. **Every URL below appears in
the Superhero repositories or in official æternity documentation.** Anything not on this page has
not been verified from those sources — which does not make it hostile, but does mean you should not
connect a wallet to it on this page's authority.

URLs are shown as literal strings rather than links in the tables, so you can compare them character
by character against whatever you were sent.

## The rule

> Superhero lives on `superhero.com` and `wallet.superhero.com`. Nothing else is the app.

Check the domain before you sign anything. A phishing site can copy the entire interface — the
palette, the logo, the copy — but it cannot copy the domain. The registered marks are also
protected: using Superhero branding on another domain is both a fraud signal and, per
[the terms](https://superhero.com/terms), a breach.

## What is not on this list

**One X account, and nothing else.** The app's own copy for the X posting reward tells you to
"mention `@superhero_chain` or link superhero.com", and the backend's reward checker treats exactly
those two strings as qualifying (`superhero/src/locales/en.json`;
`superhero-api/src/profile/profile.constants.ts`). So:

| Channel | URL | Evidence |
| --- | --- | --- |
| X | `https://x.com/superhero_chain` | Named in the app's own reward copy and in the backend's keyword list |

That is the complete list. **No Discord server, Telegram group, Reddit community, forum or mailing
list for Superhero appears in any of the six repositories** — the web app and its locale files, the
backend, the agent skill, the BCL contracts, the governance contracts or the tipping contract. The
other X and Telegram references in the codebase are share intents — the buttons that post *your*
content to *your* accounts — and the OG banner's description of the card used when someone shares a
link. The FAQ's reference to "official channels listed in the app" still cannot be resolved to a
concrete list.

Treat that as a live risk. An unofficial Discord or Telegram claiming to be Superhero support is the
standard setup for a key-phishing or fake-airdrop scam, and this page cannot tell you which invites
are legitimate. Use the GitHub trackers and the email address above, and assume anyone who
direct-messages you offering help is not support — including from an account that looks like the one
above.

**No other domains.** `superhero.io`, `superhero.app`, `superhero.finance`, `superheroswap.com` and
anything similar are not referenced anywhere in these repositories. A "Superhero" token sale,
airdrop, presale, migration or wallet-verification page on any domain other than the two above is
not Superhero.

**No one ever needs your key.** Not support, not a migration, not a verification, not an airdrop
claim, not a "wallet sync". Every legitimate Superhero action is a transaction you sign in your own
wallet. See [Security Best Practices](/wallets/security).

## Open questions

Each of these needs a statement from Superhero. No further code reading will settle them.

- **Is there an official community channel beyond the X account above?** The FAQ refers to "official
  channels listed in the app" in the plural. Six repositories were searched and only
  `@superhero_chain` is identifiable. If a Discord or Telegram exists, Superhero must publish it —
  **do not add an invite to this page on the strength of a search result, a social post, or someone
  saying so.** The whole value of this page is that every URL on it traces to a repository or to
  official æternity documentation.
- **Is `testnet.api.dev.tokensale.org` a permanent testnet endpoint?** The hostname still reads as a
  development deployment, and the backend repository does not name it — neither `.env.example` nor
  `.env.testnet.example` carries a testnet API hostname, so the value in the web app's
  `src/config.ts` is the only record of it. Superhero would have to state whether it is supported.
- **What availability can you expect from `mdw.wordcraft.fun`?** Its operator is now reasonably
  clear — the backend's deployment guide pulls mainnet database backups from `dev.wordcraft.fun`,
  and the API's package name (`wordcraft-api`) and Swagger title ("WORD CRAFT Scan") share the
  brand, so it is almost certainly the same team rather than a third party. What is unpublished is
  any commitment: no SLA, rate limit, version policy or maintenance window for that host appears
  anywhere.
