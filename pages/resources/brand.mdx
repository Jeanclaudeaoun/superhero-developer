# Brand & Media

The canonical brand kit is the in-app branding page at
[superhero.com/branding](https://superhero.com/branding), which serves every asset as a direct
download. The palette, typography and asset inventory below mirror it.

## Colour palette

| Name | Hex | RGB | Used for |
| --- | --- | --- | --- |
| Primary Neon Teal | `#00ff9d` | `0, 255, 157` | Core interactions, success states, primary actions |
| Neon Pink / Crimson | `#ff6b6b` | `255, 107, 107` | Error states, destructive actions, active gradients |
| Neon Blue | `#0f61fe` | `15, 97, 254` | Sub-headings, secondary buttons, informative components |
| Background | `#0a0a0f` | `10, 10, 15` | The deep dark-mode backdrop the neon hues sit on |

The background colour is also the PWA's `theme_color` and `background_color`, so it is what a mobile
browser paints around the installed app. Superhero describes the system as "our deep dark-mode
backdrop, optimized for high contrast with radiant cyberpunk neon hues." There is no light theme.

## Typography

The primary typeface is **Inter**, "an open-source, modern type family carefully crafted for high
readability on screens."

```css
font-family: 'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif;
```

Three weights carry the system: Regular for body, Semibold for emphasis, Black for headings. The
brand kit's specimens are "Attention Markets" as a heading and "Follow Trends on-chain on a
decentralized network." as body text.

## Assets

Every asset below is downloadable from [superhero.com/branding](https://superhero.com/branding).
The paths are the app's own asset paths, so they also resolve directly under `superhero.com`.

| Asset | Format | Path | Description |
| --- | --- | --- | --- |
| Full logo | SVG | `/full-logo.svg` | The main combination logo: the Superhero brand name alongside the blue power shield icon |

The branding page also offers four custom UI icons as individual SVG downloads — **diamond**,

family, and are exported from the running page rather than served as static files.

## Usage

Use the marks unmodified. Do not recolour the logo, stretch it, add your own wordmark to it, or
build a derivative mark from the shield.

Editorial and press use of the unmodified logo is permitted. Anything that could read as
endorsement — a product name, an app icon, a landing page, a token or a community that presents
itself as official — needs written permission first; ask at `superherowallet@protonmail.com`.

- **Do not use the marks on a site that collects keys or funds.** See
  [Official Links](/resources/links).
- **Community-run deployments are not official.** The interface is open source and can be deployed
  independently; if you run one, do not present it as Superhero.
- **Community tokens are not brand licences.** Creating a token named after Superhero, or using the
  logo as a token image, does not make it official and does not grant any trademark right.

## Writing about Superhero

| Convention | Correct | Avoid |
| --- | --- | --- |
| Product name | Superhero | SuperHero, Super Hero |
| Domain | superhero.com | superhero.io, superhero.app |
| Chain | æternity, with the ligature | aeternity (acceptable in plain-ASCII contexts such as the FAQ copy) |
| Coin | AE | ÆTH, AET |
| Identity | Superhero Onchain ID, SuperheroID | Superhero ID (spaced) |
| Analytics surface | Trendminer | Trend Miner, TrendMiner |
| Wallet | Superhero Wallet — a separate product from the Superhero app | Treating `wallet.superhero.com` and `superhero.com` as the same thing |

Superhero's own one-line description: "Superhero is an on-chain attention market built on the
æternity blockchain where users can discover, trade, and govern social trends."
