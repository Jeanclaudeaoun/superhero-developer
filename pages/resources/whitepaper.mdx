# Whitepaper

The Superhero technical whitepaper (**version 0.7, February 2026**) is the protocol's prose
specification: the design principles, the identity, posting, community-factory and DAO models, the
exponential bonding curve, the affiliation token sale, the system architecture and the token
economics. It is published in-app at [superhero.com/whitepaper](https://superhero.com/whitepaper).

Read it for the reasoning behind the protocol. For entrypoint signatures, addresses, endpoints and
worked numbers, use the pages in the table below.
