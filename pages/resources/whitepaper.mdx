# Whitepaper

The Superhero technical whitepaper, **version 0.7, February 2026**, is published in-app at
[superhero.com/whitepaper](https://superhero.com/whitepaper). It is the protocol specification these
docs are built from: when a number here disagrees with the whitepaper, the whitepaper is the source
and this site has the bug. Use this page to find the right section fast, and to jump from a section
to the page that expands it.

The whitepaper renders as Markdown with GitHub-flavoured tables and KaTeX math in the app itself.
There is no PDF — see the open questions.

## How to read it

If you are **new to the product**, read Abstract, Introduction and Design Principles, then stop and
come back to this site — the middle sections assume you know what a bonding curve is.

If you are **building an integration**, the useful sections are Superhero Onchain ID, Posting &
Tipping, Community Factory, and System Architecture. They describe data models and deployment
structure; they do not give you entrypoint signatures, which are in the ACIs shipped with the
[agent skill](https://github.com/superhero-com/superhero-agent-skill) and documented under
[Smart Contracts](/contracts).

If you are **trying to reconcile a number**, go straight to Exponential Bonding Curve and Token
Economics Summary, then to [Where the Money Goes](/concepts/value-flow), which works the same
arithmetic through a concrete trade and flags the places where the app's behaviour and the
whitepaper's rounding differ.

If you are **assessing risk**, read Security Considerations alongside the honest caveats in
[Risks](/tokens/risks) and the failure modes in [Attention Markets](/concepts/attention-markets).
Note the whitepaper's own wording: the contract suite is "designed for independent audit and formal
verification" — designed for, not audited.

## Open questions

- **Is there a downloadable PDF?** The whitepaper is a Markdown string rendered client-side in
  `src/views/Whitepaper.tsx`. No PDF asset exists in the repository's `public/` directory and no
  download link appears in the app.
- **Is there a version history?** The document is labelled "Version 0.7 — February 2026" with no
  changelog, and versions 0.1 through 0.6 are not published anywhere in these repositories. A reader
  who needs to know what changed between versions has nothing to compare against.
