# Tokens & Bonding Curves

Every Superhero community token is an AEX-9 token minted and burned against an **exponential bonding
curve**. There is no order book and no counterparty: you always trade against the curve, price is a
pure function of supply, and the contract always holds enough reserve to buy the entire supply back.

This section is written so that by the end of it you can launch a token, price a trade by hand, and
explain where every fraction of the fee goes.

## The numbers to remember

| Fact | Value |
| --- | --- |
| Curve | `buy(x) = 0.001 · e^(0.00000001 · x) − 0.0009999`, in AE per token |
| Sell curve | `sell(x) = buy(x) · 0.995` |
| Price of a trade | The integral of the curve across the supply you mint into or burn out of |
| Launch price | 0.0000001 AE per token, at supply 0 |
| Spread | 1% of the curve value — 0.5% to the community DAO, 0.5% to affiliation |
| Instant round trip | Returns 0.99502 of what you paid, before gas |
| Affiliation split | 0.300% / 0.125% / 0.050% / 0.025% across four referral levels; burned if unreferred |
| ProtocolDAO reward | Minted to the buyer on every buy, proportional to its AE value |
| Token standard | AEX-9, 18 decimals |
| Solvency | The sell curve is strictly below the buy curve at every supply, so the reserve always covers the full supply |
