# Transaction History

> **Page brief** — A reference for the transaction views, useful both for research and for agent pre-trade checks.
>
> `status: outline` · `depth: standard`

```bash
node scripts/superhero-transactions.mjs mine [limit]
node scripts/superhero-transactions.mjs token ct_... [limit] [page]
node scripts/superhero-transactions.mjs account ak_... [limit]
node scripts/superhero-transactions.mjs all [limit]
node scripts/superhero-transactions.mjs activity ct_... ak_... [limit]
```

| Field | Meaning |
| --- | --- |
| `type` | `buy` or `sell` |
| `ae_amount` | AE paid or received |
| `amount` | Token quantity |

A useful pre-buy heuristic from the agent guides: many small buyers suggests organic
momentum; one large buyer suggests a pump with higher exit risk.
