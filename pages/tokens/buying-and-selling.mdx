# Buying & Selling

> **Page brief** — The trading reference. Must cover quoting, slippage protection, allowances and confirmation.
>
> `status: outline` · `depth: deep`

### From the token page

Open a token, use the trade card, choose Buy or Sell, review the live quote, and confirm in
your wallet. Tokens are minted or burned against AE along the bonding curve.

### From the command line

```bash
node scripts/superhero-token-swap.mjs lookup "TokenName"          # resolve a name to a sale address
node scripts/superhero-token-swap.mjs price ct_<sale_address> 10  # AE cost for 10 tokens
node scripts/superhero-token-swap.mjs buy   ct_<sale_address> 5
node scripts/superhero-token-swap.mjs sell  ct_<sale_address> 5
```

Both `buy` and `sell` apply **3% slippage protection** automatically. `sell` also handles the
AEX-9 allowance for you.

### The underlying contract calls

| Entrypoint | Notes |
| --- | --- |
| `buy(count)` | Payable. Mints `count` tokens to the caller. |
| `buy_with_affiliation(count, affiliation_rewardee)` | Payable. Same, but routes the affiliation fee. |
| `sell(count, minimal_return_required)` | Burns tokens; reverts if the return is below the floor. |
| `buy_price(count)` / `sell_return(count)` | Quote before trading. |
