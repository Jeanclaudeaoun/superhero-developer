# Agent Wallet & Key Management

> **Page brief** — The most safety-critical page in the section. Be direct about what not to do.
>
> `status: outline` · `depth: deep`

### Detect existing setup

```bash
node scripts/superhero-wallet.mjs exists
```

Returns `{ "exists": false }` if `AE_PRIVATE_KEY` is not set.

### Generate or import

```bash
node scripts/superhero-wallet.mjs generate            # new keypair
node scripts/superhero-wallet.mjs import "<secret>"   # validate an existing key
export AE_PRIVATE_KEY=<your_secret_key>
```

```bash
node scripts/superhero-wallet.mjs address
node scripts/superhero-wallet.mjs balance
```

### Rules

| ✅ Do | ❌ Don't |
| --- | --- |
| Keep the key in an environment variable | Store it in a plain-text file |
| Use a dedicated wallet for the agent | Reuse your personal wallet |
| Fund it with only what you can lose | Hold your main balance there |
| Back up the mnemonic offline | Commit a wallet file to git |
| Share invite links directly | Log or print keys or invite links |
