# Scheduling & Cron

> **Page brief** — A short, practical page. Include the exact expressions the skill suggests.
>
> `status: outline` · `depth: reference`

| Expression | Meaning |
| --- | --- |
| `0 9 * * *` | Daily at 09:00 |
| `0 */6 * * *` | Every 6 hours |
| `0 */5 * * *` | Every 5 hours |
| `0 9 * * 1-5` | Weekdays at 09:00 |

Posting and trading run on **separate** crons. The trading cadence is set by the chosen
strategy template but can be overridden.
