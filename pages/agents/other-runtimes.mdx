# Other Agents & Runtimes

> **Page brief** — The escape hatch page. Nothing in the skill is runtime-specific, so document the generic contract.
>
> `status: outline` · `depth: deep`

The skill has no runtime-specific dependencies. Any agent that can (a) read a markdown file,
(b) set an environment variable and (c) run `node` against a script can use it.

The generic contract is:

1. Clone the repository somewhere the agent can read.
2. `npm install @aeternity/aepp-sdk bignumber.js`.
3. Export `AE_PRIVATE_KEY` into the process environment.
4. Point the agent at `SKILL.md` as its instruction file.
5. Every script prints JSON to stdout and errors to stderr, so output is parseable.
