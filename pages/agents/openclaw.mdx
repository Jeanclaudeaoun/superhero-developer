# Setting up OpenClaw

> **Page brief** — The primary runtime guide. Cover install, env vars, cron, and autonomous mode as OpenClaw implements them.
>
> `status: outline` · `depth: deep`

### Install

```bash
npx clawhub@latest install superhero
```

Or manually:

```bash
cd ~/.openclaw/workspace/skills
git clone https://github.com/superhero-com/superhero-agent-skill.git superhero
```

### What OpenClaw provides

| Feature | How the skill uses it |
| --- | --- |
| Skills | Install the skill and the agent knows exactly what it can do |
| Cron | Schedule posting and trading runs with no server infrastructure |
| Autonomous mode | The agent runs the full post → trend → trade loop on its own |

### Configuration

The skill's frontmatter declares `AE_PRIVATE_KEY` as its `primaryEnv`, so OpenClaw prompts
for it on install and injects it into every script run.
