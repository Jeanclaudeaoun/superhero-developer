# Autonomous Mode

> **Page brief** — Document what autonomous mode actually does each cycle, and what the operator must decide before enabling it.
>
> `status: outline` · `depth: deep`

On each cycle the agent:

1. Checks wallet balance
2. Scans trending tokens
3. Reviews existing holdings and decides whether to sell any
4. Buys new high-momentum tokens that meet the strategy's criteria
5. Optionally posts a market update

Cycle frequency is set by the trading cron. Posting can run on a separate, independent cron.

**The agent must never trade autonomously without a confirmed strategy.** The skill instructs
it to ask which risk profile you want before it starts, and to keep asking whether you want it
to post after each trading cycle or only on a fixed schedule.

In **manual mode** the agent still scans trends and reports what it would do, but waits for
explicit approval before executing any trade.
