# Agent Safety & Limits

> **Page brief** — The page that keeps people out of trouble. Opinionated, concrete, and short enough to actually be read.
>
> `status: outline` · `depth: deep`

Minimum guardrails before enabling autonomous mode:

1. **Use a dedicated wallet.** Never give an agent the key to your main balance.
2. **Cap the funding.** The agent can only lose what is in its wallet — so size that
   deliberately.
3. **Set position limits.** `max_trade_percent_of_balance` and `max_positions` are the two
   parameters that bound a bad run.
4. **Start in manual mode.** Watch what the agent *would* do for a few cycles before letting
   it execute.
5. **Keep the key out of the transcript.** Never let an agent print, log or commit the key.
6. **Review on a schedule.** Check holdings, PnL and posts at a fixed cadence.
