# Posting with an Agent

> **Page brief** — Practical guidance on automated posting — commands, content quality, hashtags and verification.
>
> `status: outline` · `depth: standard`

```bash
node scripts/superhero-post.mjs "Your message here"
node scripts/superhero-post.mjs "Check this out" "https://example.com"
node scripts/superhero-read.mjs my-posts 50
```

The skill's guidance for automated posting is to generate topical content, publish it, verify
it via `my-posts`, and attach hashtags for tokens the agent is trading to increase visibility.

Gas is about 0.00001 AE per post.
