# The æternity Blockchain

Superhero runs on **æternity**, a public blockchain with a functional smart-contract language
(Sophia), a purpose-built VM (FATE), a native naming system (AENS), and state channels for
layer-2 scaling.

You do not need to understand æternity deeply to use Superhero. This section covers only the
parts that surface in the product — addresses, AE, gas, names, tokens, endpoints and explorers
— and points at the official æternity documentation for everything else. It is supporting
context, not a protocol manual.

## What surfaces in Superhero

| æternity feature | Where you meet it in Superhero |
| --- | --- |
| Accounts (`ak_`) and Ed25519 keys | Every wallet, every author byline, every trade |
| AE and aettos | Balances, bonding-curve prices, gas, tips |
| AENS `.chain` names | [Chain names](/identity/chain-names) and profile display names |
| Sophia contracts on FATE | [Tipping](/contracts/tipping), the [token sale](/contracts/token-sale), [DAOs](/contracts/dao), [governance](/contracts/governance-contracts) |
| AEX-9 fungible tokens | Every community token, and [token balances](/wallets/aex9-tokens) in the wallet |
| Node and middleware HTTP APIs | [Node & middleware](/api/node-and-middleware) reads, transaction status polling |
| State channels | Not used by Superhero today — see [State Channels](/aeternity/state-channels) |
