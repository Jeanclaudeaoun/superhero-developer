# The æternity Blockchain

> **Page brief** — The supporting section. Explain æternity only insofar as it affects Superhero, and link out for the rest. This is context, not the main story.
>
> `status: outline` · `depth: overview`

Superhero runs on **æternity**, a public blockchain with a functional smart-contract language
(Sophia), a purpose-built VM (FATE), a native naming system (AENS), and state channels for
layer-2 scaling.

You do not need to understand æternity deeply to use Superhero. This section covers the parts
that surface in the product — addresses, AE, gas, names, tokens and explorers — and points
elsewhere for everything else.

> For the full protocol documentation, see the official æternity documentation. These pages
> deliberately stay scoped to what a Superhero user or integrator actually needs.
