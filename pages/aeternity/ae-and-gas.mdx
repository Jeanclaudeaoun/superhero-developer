# AE & Gas

> **Page brief** — Pin down units and real costs. Unit confusion (AE vs aettos) is the single most common integration bug.
>
> `status: outline` · `depth: standard`

AE is the native coin: it pays for gas and is the base currency of every bonding curve.

Observed costs from the agent skill's guides:

| Action | Approximate cost |
| --- | --- |
| Publish a post | ~0.00001 AE |
| Create a token | ~0.001 AE gas, plus any initial buy |
| Create a governance poll | ~0.02 AE (two transactions) |
