# Sophia & FATE

> **Page brief** — Orient a developer coming from Solidity. What is familiar, what is different, what to read next.
>
> `status: outline` · `depth: standard`

**Sophia** is a functional, strongly-typed contract language with no mutable global state —
properties that reduce the surface for reentrancy and state-corruption bugs. **FATE** is the
virtual machine that executes it, optimised for functional execution.

**ACI** (æternity Contract Interface) is the JSON description of a contract's interface — the
equivalent of an ABI. The ACI files in `superhero-agent-skill/contracts/` are what clients use
to call Superhero's contracts.
