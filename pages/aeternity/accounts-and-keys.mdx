# Accounts & Keys

> **Page brief** — A short reference that stops people pasting the wrong kind of address into the wrong field.
>
> `status: outline` · `depth: reference`

| Prefix | Meaning |
| --- | --- |
| `ak_` | An account (user) address |
| `ct_` | A contract address |
| `th_` | A transaction hash |
| `kh_` / `mh_` | A key-block / micro-block hash |
| `sg_` | A signature |

Superhero uses these constantly: a **sale address** is a `ct_`, a wallet is an `ak_`, and a
trade receipt is a `th_`.
