# Chain Names (AENS)

> **Page brief** — The full AENS lifecycle as it applies to Superhero users, including the auction rule and the sponsored claim.
>
> `status: outline` · `depth: deep`

### Length rule

| Name length (before `.chain`) | Result |
| --- | --- |
| 13 characters or more | Instant registration, no auction |
| 12 characters or fewer | Goes to auction |

Superhero sponsors one free claim per address for names longer than 12 characters.

### CLI lifecycle

```bash
node scripts/superhero-name.mjs available <name>     # check availability
node scripts/superhero-name.mjs register <name>      # preclaim -> claim -> point at your address
node scripts/superhero-name.mjs update <name> [addr] # repoint the name
node scripts/superhero-name.mjs extend <name>        # renew before expiry
node scripts/superhero-name.mjs resolve <name>       # name -> address
node scripts/superhero-name.mjs lookup <address>     # address -> name
```
