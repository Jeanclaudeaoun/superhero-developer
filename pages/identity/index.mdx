# Identity

Your identity on Superhero is your æternity address plus whatever you choose to attach to it.
The `ProfileRegistry.aes` contract holds profiles and public names on-chain, so there is no
account system to be locked out of and no operator who can revoke your handle. Everything else
— avatars, bios, linked X handles — hangs off that address through signed, verifiable links.

## The shape of an identity

| Layer | What it is | Where it lives |
| --- | --- | --- |
| Address | `ak_…` public key derived from your seed | The æternity chain; you hold the key |
| Chain name | An AENS `.chain` name pointed at your address | AENS, a protocol-level name system |
| Custom name | A self-declared handle claimed in the registry | `ProfileRegistry.aes` |
| X name | An X handle bound to your address by attestation | `ProfileRegistry.aes` plus a backend signer |
| Profile fields | Fullname, bio, avatar URL, website, Nostr key | Registry state and the Superhero API |

A name is never the identity. Resolution always ends at an address, and the three name types
differ only in how much evidence backs them. Read [Names](/identity/names) before you assume a
displayed handle means anything.
