# Identity

Your identity on Superhero is your æternity address plus whatever you choose to attach to it.
Attachments are provider links in the `AddressLink` contract, each authorised by your own
signature over a nonce-bearing message. There is no account to be locked out of, and only you
can remove a link.

## The shape of an identity

| Layer | What it is | Where it lives |
| --- | --- | --- |
| Address | `ak_…` public key derived from your seed | The æternity chain; you hold the key |
| Preferred AENS name | A `.chain` name you own and linked | `AddressLink`, provider `prefaens`, ownership checked on chain |
| Chain name | An AENS name resolved for your address | The Superhero API, refreshed hourly from the middleware |
| X handle | An X handle you linked after OAuth | `AddressLink`, provider `x` |
| Nostr key | The npub your chat identity uses | `AddressLink`, provider `nostr` |
| Bio and website | Free-text links | `AddressLink`, providers `bio` and `site` |
| Fullname, avatar, username | Legacy profile fields, read-only | The Superhero API |

A name is never the identity. Resolution always ends at an address, and the name types differ
in how much evidence backs them — see [Names](/identity/names).
